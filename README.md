# Kelime Kartları
1. Bu klasörü GitHub'a yükle (push et).
2. GitHub > Actions > "APK Derle" tamamlanınca en alttaki **Artifacts** kısmından `kelime-kartlari-apk` dosyasını indir.
3. Zip içindeki `app-debug.apk` dosyasını telefona kur.

Dosya formatı (.txt / .csv), her satır bir kelime:
apple,elma
to give up - vazgeçmek
